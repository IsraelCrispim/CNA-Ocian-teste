# CNA Ocian — Missão

Projeto separado do HTML original em arquivos de assets.

## Estrutura
- `index.html` — estrutura da interface
- `css/style.css` — estilos e animações
- `js/game.js` — lógica do jogo, fases e perguntas
- `img/personagens/ingles.png` — personagem de inglês
- `img/personagens/robotica.png` — personagem de programação e robótica
- `img/mapas/london.png` — mapa de Londres
- `img/mapas/cybertec.png` — mapa Cybertec

Abra `index.html` no navegador para executar.
